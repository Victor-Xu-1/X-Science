安装 X-Science Link

按顺序完成下面步骤。安装或重新加载扩展后，需要刷新当前 X-Science 页面才能检测到。

⬇️
01

下载 X-Science Link

在 X-Science 的“X-Science Link”页面点击“下载 X-Science Link”，得到一个 ZIP 文件。

📦
02

解压并保留文件夹

右键 ZIP 选择“全部解压”。解压后的 X-Science Link 文件夹不要删除或移动。

🧩
03

打开扩展管理页

在浏览器地址栏输入 chrome://extensions 或 edge://extensions，然后回车。

🔛
04

打开开发者模式

在扩展管理页右上角打开“开发者模式”。Edge 可能在左侧或底部。

📁
05

加载已解压的扩展

点击“加载已解压的扩展程序”，选择第 2 步解压出来的 X-Science Link 文件夹。

✅
06

刷新页面检测

回到 X-Science，刷新当前页面，再点击“连接”。连接成功后，以后打开 X-Science 会自动连接。

注意事项

浏览器会要求你确认添加 X-Science Link，这是安全保护。请只从 X-Science 页面下载，并在扩展管理页选择刚才解压出来的文件夹。

English

Install X-Science Link

Download the ZIP, extract it, open chrome://extensions or edge://extensions, enable Developer mode, choose “Load unpacked”, and select the extracted X-Science Link folder. Return to X-Science, refresh the page, then click Connect.
